# OrganoidIntelligence

OrganoidIntelligence es una hoja de ruta para conectar organoides cerebrales, ingeniería organ-on-chip, interfaces MEA y computación biológica de ciclo cerrado.

- Web: [ideas.onlyideas.art](https://ideas.onlyideas.art)
